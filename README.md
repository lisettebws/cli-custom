These need to be sourced in your `.bashrc` or `.bashprofile`

Similar to/overlaps with my in ktd files: https://github.com/lisettebws/shared 

Includes functions for making git branches, deleting the current branch, git log options, git stash options, a script I run on reboot, making ktd proxy boxes and bringing them down, making git worktrees and cleaning them up.

There's also `functions` to get a list of all the functions and a `readfunction` that will list all the functions and then show you the code of the function you type in. 

The `.bashprofile` file is just the colors I define and use in some functions, it can be amended to your .bashprofile
